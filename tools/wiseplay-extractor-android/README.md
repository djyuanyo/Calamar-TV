# Extractor Wiseplay — APK Android

Extrae nombres y URLs de listas Wiseplay W3U (incluidas sublistas) y M3U, y exporta TXT o CSV. No reproduce ni desbloquea señales.

## APK
1. Abre la pestaña Actions del repositorio.
2. Abre **Compilar Extractor Wiseplay APK** en la rama `android/wiseplay-extractor-apk`.
3. Descarga el artefacto **Extractor-Wiseplay-APK**, descomprímelo e instala `app-debug.apk` en Android.

Build: JDK 17, Gradle 8.9, AGP 8.7.3, Android API 35.
APK de pruebas firmada con clave debug; no destinada a Google Play.
No expongas enlaces con credenciales y utiliza únicamente fuentes a las que tengas autorización.
