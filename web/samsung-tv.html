Calamar TV para Samsung TV

Versión de prueba para Tizen 7.0 o posterior. Descarga el paquete WGT en un ordenador para firmarlo e instalarlo en tu televisor.

Descargar WGT de prueba

  1. Instala Tizen Studio, Samsung TV Extensions y Samsung Certificate Extension en el ordenador.
  2. Conecta la tele y el ordenador a la misma red. Activa el modo desarrollador en Apps, introduce la IP del ordenador y reinicia la tele.
  3. Conecta la tele desde Device Manager. Crea un perfil de certificado Samsung TV para el DUID de la tele.
  4. En Tizen Studio, importa el WGT con File → Import → Tizen Project. Selecciona el perfil TV y elige Run As → Tizen Web Application para firmarlo e instalarlo.

Si el navegador de tu Samsung bloquea las descargas, abre esta página desde el ordenador.
